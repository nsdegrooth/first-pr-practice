# First PR Practice

A tiny practice repo for shipping a first pull request on GitHub.

## What this is

This repo exists purely to practice the workflow: clone, branch, commit, push, and open a pull request.

## Usage

There's nothing to run here — it's just a README.

## Getting Started

1. Clone this repo: `git clone https://github.com/nsdegrooth/first-pr-practice.git`
2. Create a branch: `git checkout -b my-change`
3. Make your edit and commit it: `git commit -am "Describe your change"`
4. Push and open a pull request: `git push -u origin my-change`
